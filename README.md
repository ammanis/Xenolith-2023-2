# Xenolith - C Language Only
<img width="2001" height="1129" alt="image" src="https://github.com/user-attachments/assets/fa29c2f3-6494-4157-a674-1cd25a780173" />

This game is inspired by Space Invaders, where players pilot a laser cannon or battle aircraft at the bottom of the screen to defend Earth from alien invaders. Players must shoot down enemies before they reach the bottom while facing progressively increasing difficulty levels and utilizing support items to complete each stage. The game features simple yet addictive gameplay.

1. Download Xenolith exe.exe
2. When "Windows protected your PC" popped up, click "More info"
3. Then click "Run anyway"
